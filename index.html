FAQ

    
What is Pterodaktil?
A collection of 1,600 pixel-art pterodactyl NFTs in 16 tiers on BNB Chain. Each tier has exactly 100. Mints draw a random tier from the deck — any mint can land any tier.

    
How much does it cost to mint?
Your first mint is FREE if you hold a SPACE ID Agent ID. Then the ladder: 2nd mint 0.0005, 3rd 0.001, 4th 0.002, 5th 0.003, 6th 0.005 BNB. Max 6 per wallet, so the most one wallet ever pays is 0.0115 BNB.

    
Do I need an Agent ID to mint?
Yes — both the free mint and paid mints require a SPACE ID Agent ID in the minting wallet. There is no allowlist: any Agent ID holder can mint. Use the Agent ID checker above to test a wallet. Minting is agent-only: there is no wallet mint button on this page — copy the agent prompt and give it to your agent.

    
What is $PTRO?
The bonus token of the flock. Every mint accrues $PTRO by tier (free mint: 10; paid: 1,000–128,000). Burning 5 NFTs for a Paragon accrues 384,000. Claim it any time from the token contract. Total supply is fixed at 100,000,000.

    
How does the Paragon burn work?
Burn any 5 Pterodaktils you own and you forge 1 Paragon (the highest tier) plus 384,000 $PTRO. Only 10 Paragons can ever be forged by burn; the other 90 are in the random mint deck.

    
Is this the same as the old Pterodaktil?
No — this is a new edition with new pixel art, new ladder pricing, the $PTRO bonus token and the Paragon burn. The 2026 Pterodaktil contract (1,600 supply, 0 minted) is untouched and stays where it is.
